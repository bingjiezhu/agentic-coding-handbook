# Terminology · 术语对照

The Chinese and English editions use the following terms consistently. Chapter structure, prompt examples, filenames and command syntax correspond across editions. Product names and executable identifiers retain their official spelling.

中英文版本采用以下术语。章节、提示词示例、文件名和命令保持对应，产品名称与可执行标识保留官方拼写。

| 中文 | English used here | Meaning in this handbook |
| --- | --- | --- |
| 编程智能体 | coding agent | A tool-using assistant that can work with project files and execution tools |
| 需求规格 / 规格 | specification / spec | Goals, behavior, constraints and acceptance criteria |
| 完成标准 / 验收标准 | acceptance criteria | Observable conditions for accepting work |
| 上下文 | context | Information available to the agent for its current task |
| 会话压缩 | context compaction | Condensing earlier conversation; not rewriting saved project files |
| 基线 | baseline | A preserved reference version used for comparison and recovery |
| 复现 | reproduce / reproduction | Triggering the issue under recorded conditions |
| 回归检查 | regression check | Detecting a recurrence or a change that breaks existing behavior |
| 只读 | read-only | An intended scope; enforcement requires actual access controls |
| 子智能体 | subagent | An actual tool-supported agent task, not a simulated role in one reply |
| 独立审查 | independent review | Review by a party not involved in implementation, with the relevant scope limits |
| 规则 / 技能 | rules / Skills | Persistent project guidance / reusable task-specific methods |
| Hook / 钩子 | Hook | A configured event mechanism; recording and blocking are different behaviors |
| 未验证 | unverified | A check that has not established the claim, not a pass |
| 判断力 / taste | judgment / taste | Understanding users and setting priorities; a definition used in this guide |

## Language conventions · 语言约定

The Project Guide instructions use English as a shared format across coding agents. During project work, the guide responds in the user's language. Reference chapters are read as needed for the current task.

项目引导技能以英文作为通用指令格式，实际沟通使用用户的语言。参考章节根据当前任务按需读取。
